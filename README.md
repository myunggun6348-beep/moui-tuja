# 모의투자 연습 앱

모바일에서 보기 쉬운 로그인, 이용 안내, 투자 현황, 매수·매도, 주문내역을 제공합니다. 가상 종목과 고정 예시 가격을 사용하며 실제 주식 주문은 보내지 않습니다.

- 이메일 계정: Supabase 로그인 링크(PKCE)와 사용자별 PostgreSQL 기록
- 화면 연습: 로그인 없이 같은 브라우저에 연습 기록 저장
- 새 계정: 가상 현금 1,000만 원, 보유 주식 0주
- 종목 찾기: 이름·연습 코드 검색, 관심종목 필터, 선택한 종목의 매수 화면으로 이동
- 관심종목: 로그인 시 계정에 저장, 화면 연습 시 브라우저에 저장

기존 서비스의 닉네임·PIN 계정과 기록은 자동 이전되지 않습니다. 기존 서버 원본은 이 저장소에 없습니다.

현재 이메일 기본 발송은 관리자 테스트 주소로 제한됩니다. 일반 사용자에게 공개하기 전 별도 SMTP 발송 서비스 연결과 실제 로그인 검증이 필요합니다.

## 코드

`prototypes/`에는 웹 화면, `api/`에는 공개 설정 API, `database/`에는 사용자별 데이터 분리 및 주문 저장 SQL이 있습니다. 환경 변수와 비밀 키는 저장소에 포함하지 않습니다.

설정은 [database/SETUP.md](database/SETUP.md)를 참고하세요. Node.js 24에서 `npm install` 후 `npm test`로 검증합니다.
