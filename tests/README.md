# 검증

Node.js 24에서 `npm install` 후 `npm test`를 실행합니다.

- 브라우저 연습 기록 저장, 새로고침, 수수료, 매도 세금, 저장 실패
- 이메일 인증 요청, 탭 세션, 토큰 갱신, 비밀 키 공개 차단
- PostgreSQL 기반 사용자별 데이터 분리, 직접 수정 차단, 중복 주문 방지, 잔액과 보유 수량 제한

DB 테스트는 로컬 PGlite PostgreSQL을 사용하며 실제 서비스 계정과 데이터는 변경하지 않습니다. 배포 환경의 실제 이메일 발송과 기기 간 동시 거래는 서비스 연결 후 별도 확인이 필요합니다.
